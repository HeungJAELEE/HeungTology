# [[[Battery] image-transformation-affine

## 💡 왜 이것을 배우는가? (Why)
물체는 항상 고정된 위치에 있지 않습니다. 카메라가 흔들릴 수도 있고, 물체가 회전하거나 멀어질 수도 있습니다. 인공지능이 이러한 **'위치 변화'**에도 굴하지 않고 물체를 인식하려면, 이미지를 밀고, 당기고, 돌리는 수학적 변환 기술이 필수적입니다. 

> [!TIP]]
> **비유**: 기하학적 변환은 마치 **'고무 찰흙을 주무르는 것'**과 같습니다. 찰흙 자체의 성질(픽셀 값)은 변하지 않지만, 잡아당기거나(`Scale`) 돌려서(`Rotate`) 모양과 위치를 바꾸는 것과 동일한 원리입니다.

## 상세 설명

### 1. 어파인 변환 (Affine Transform)
영상의 직선 관계(평행성)를 유지하면서 이동, 회전, 스케일링을 수행하는 변환입니다. 2x3 행렬 하나로 이 모든 동작을 정의할 수 있습니다.

- **이동 (Translation)**: $x, y$ 좌표를 일정한 수치만큼 이동.
- **스케일링 (Scaling)**: 이미지의 크기를 확대하거나 축소.
- **회전 (Rotation)**: 특정 지점을 기준으로 이미지를 회전. 

### 2. 좌표계의 주의점 (중요!)
실무에서 가장 많이 실수하는 부분입니다.
- **OpenCV 함수**: `(x, y)` 순서로 좌표를 입력합니다. (가로, 세로)
- **NumPy 행렬**: `(row, col)` 즉 `(y, x)` 순서로 접근합니다. (세로, 가로)
> [!IMPORTANT]
> 코딩 시 이 순서가 반대이기 때문에, 행렬 인덱싱과 함수 인자를 혼동하면 결과 이미지가 뒤집히거나 런타임 에러가 발생합니다.

### 3. OpenCV 회전 구현
OpenCV는 회전과 스케일링을 한꺼번에 처리하는 편리한 함수를 제공합니다.
```python
# 중심점, 회전각, 스케일을 입력하여 변환 행렬 생성
M = cv2.getRotationMatrix2D(center, angle, scale)

# 행렬을 이미지에 적용
dst = cv2.warpAffine(src, M, (width, height))
```
