# [[[Battery] outlier-robust-scaling

## 1. [왜 배우는가? (Why)]]
데이터 속에 숨어있는 **'이상치(Outlier)'**는 머신러닝 모델에게는 독과 같습니다. 특히 평균과 표준편차에 의존하는 일반적인 스케일링(StandardScaler) 방식은 단 몇 개의 극단적인 값만으로도 전체 데이터의 균형을 무너뜨려 모델을 혼란에 빠뜨립니다.

우리가 **로버스트 스케일링**과 **피처 변환**을 배우는 이유는 **"데이터의 본질적인 분포를 유지하면서도 이상치의 충격을 수학적으로 흡수하기 위함"**입니다. 비대칭이 심한 데이터를 예쁘게 다듬고, 이상치에 흔들리지 않는 단단한 기준(Median, IQR)을 세움으로써, 모델이 사소한 소음에 휘둘리지 않고 데이터의 핵심 패턴에만 집중할 수 있는 깨끗한 환경을 조성하는 과정입니다. 이는 [AI] data-quality-audit을 통해 발견된 이상치를 모델이 소화 가능한 형태로 '순치'시키는 핵심 공정이며, [AI] dataloader-optimization 파이프라인에 통합되어 고속으로 처리되어야 합니다.

## 2. [로버스트 성능 사양 (Robustness Specs)]
| 제어 파라미터 | 정밀 타겟 / 수치 | 비고 |
| :--- | :--- | :--- |
| **IQR Target Range** | $[Q_1, Q_3]$ | 데이터의 50%가 집중되는 핵심 구간 |
| **Outlier Detection Recall** | $\ge 0.98$ | 실제 이상치를 탐지/격리해낼 확률 |
| **Skewness Reduction** | $< 0.5$ (Abs) | 변환 후 목표로 하는 분포의 왜도(Skewness) |
| **Quantile Precision** | $0.01$ | 분위수 계산 시의 해상도 (n_quantiles 설정) |
| **Transformation Latency** | $< 5\text{ms}$ | 실시간 추론 시 허용되는 최대 변환 지연 |

## 3. 핵심 기법 및 수리적 분석

### 2.1 RobustScaler (이상치 내성 스케일링)
평균 대신 **중앙값(Median)**과 **사분위수(IQR)**를 사용하여 스케일링합니다.
- **수식**: $x_{scaled} = \frac{x - \text{median}}{\text{IQR}}$ (여기서 $\text{IQR} = Q_3 - Q_1$)
- **특징**: 전체 데이터의 50%가 모여 있는 '몸통' 구간을 기준으로 정규화하므로, 꼬리(Tail) 부분에 위치한 이상치가 스케일 범위 전체를 좌지우지하는 현상을 방지합니다.

### 2.2 Power Transformer (분포 정규화)
비정규 분포를 강제로 정규분포에 가깝게 변환하여 선형 모델의 성능을 극대화합니다.
- **Yeo-Johnson 변환**: 0이나 음수가 포함된 데이터에도 적용 가능한 범용적 기법입니다.
- **수식 (개념)**: $\lambda$라는 파라미터를 최적화하여 왜도(Skewness)를 0에 가깝게 만듭니다.

### 2.3 Quantile Transformer (강제 정규화)
데이터의 순위(Rank) 정보를 이용하여 강제로 정규분포나 균등분포로 펼칩니다. 이상치의 절대적인 크기보다 **'상대적인 순서'**가 중요할 때 가장 강력한 도구가 됩니다.

## 3. [코드 연결 해설 (Code Weaving)]

Scikit-learn을 활용하여 다양한 스케일러의 효과를 비교 적용하는 코드를 해설합니다.

```python
from sklearn.preprocessing import RobustScaler, QuantileTransformer
import numpy as np

# 1. 이상치가 포함된 가상의 데이터 생성 (100은 극단적 이상치)
data = np.array([1, 2, 3, 100]).reshape(-1, 1)

# 2. RobustScaler 적용: 중앙값 기준으로 스위칭
robust = RobustScaler()
scaled_robust = robust.fit_transform(data)
# 결과: 중앙값(2.5) 주변은 0 근처에, 이상치는 약 48.5 정도로 유지됨

# 3. QuantileTransformer 적용: 정규분포로 강제 매핑
quantile = QuantileTransformer(output_distribution='normal', n_quantiles=4)
scaled_quantile = quantile.fit_transform(data)

# 알고리즘은 이를 단순히 '가장 높은 순위의 값'으로 해석하여 전체 분포의
```

## 4. 실무 응용 사례 (Verified 2026)

- **금융 (Fraud Detection)**: 사기 거래 데이터는 극단적인 수치를 동반하는 경우가 많습니다. 이때 `RobustScaler`를 사용하면 정상 거래 데이터의 분포를 해치지 않으면서도 이상 징후를 명확히 분리해낼 수 있습니다.
- **제조 (센서 데이터)**: 센서 노이즈로 인한 튀는 값들이 빈번할 때, `Power Transformer`를 통해 데이터를 정규화하면 이상 감지 알고리즘의 오탐율(False Positive)을 획기적으로 낮출 수 있습니다.

## 5. [스스로 체크 (Self-Check)]

1. **질문**: 왜 이상치가 있는 데이터에서 `StandardScaler`보다 `RobustScaler`가 유리한가?
   - **정답**: `StandardScaler`는 이상치에 민감한 **평균과 표준편차**를 사용하여 전체 범위를 왜곡하지만, `RobustScaler`는 이상치의 영향을 거의 받지 않는 **중앙값과 사분위수(IQR)**를 기준으로 삼기 때문입니다.
2. **질문**: `PowerTransformer`의 핵심적인 수학적 목적은 무엇인가?
   - **정답**: 데이터의 **비대칭성(Skewness)을 제거**하여 정규분포를 가정하는 모델(선형 회귀, LDA 등)이 데이터의 패턴을 더 명확하게 학습할 수 있도록 돕는 것입니다.
3. **질문**: [AI] data-quality-audit에서 극단적인 이상치가 대량으로 발견되었을 때 `QuantileTransformer` 사용 시 주의할 점은?
   - **정답**: 데이터의 수치적 간격(Magnitude) 정보를 소실시키고 오직 **순위 정보**만 남기므로, 값들 사이의 미세한 차이가 중요한 물리적 의미를 갖는 경우에는 오히려 정보 손실이 발생할 수 있음을 인지해야 합니다.

## 🧠 AI의 사고방식: "거친 파도를 잠재우는 수학적 방파제"
AI에게 이상치는 평화로운 호수에 던져진 커다란 바위와 같습니다. 그 파동은 모델이라는 배를 뒤흔들어 항로를 이탈하게 만듭니다. **로버스트 스케일링**은 그 충격을 흡수하는 완충 장치이며, **피처 변환**은 거친 파도를 잔잔한 물결로 바꾸는 방파제입니다. 우리는 이 수학적 도구들을 통해 데이터라는 바다를 안정시키고, AI가 폭풍우 속에서도 길을 잃지 않고 정확한 목적지를 향해 나아갈 수 있도록 돕는 항해사입니다.
