# [[[Semiconductor] background-subtraction

## 1. [왜 배우는가? (Why: Finding Change)]]
보안 카메라에서 '침입자'를 찾거나 도로 위 '달리는 차'를 감지하려면 무엇이 움직이는 것인지 알아야 합니다. 배경(움직이지 않는 것)과 현재 화면을 비교하여 **'달라진 부분'**만 골라내는 과정은 지능형 영상 분석의 가장 기초적인 객체 분리 기술입니다.

> [!TIP]
> **비유**: 배경 차분은 마치 **'숨은 그림 찾기'**와 같습니다. 정답지(배경)를 미리 알고 있고, 현재 그림(현재 프레임)에서 정답지와 다른 부분만 펜으로 칠해나가며 움직이는 범인을 찾아내는 과정입니다.

## 2. 핵심 기술 사양 (Numerical Specs)

배경 모델링의 정밀도를 결정하는 파라미터 및 수식입니다.

| 항목 (Parameter) | 수식 / 특징 | 물리적 의미 |
| :--- | :--- | :--- |
| **Absolute Difference** | $D = |f_t - B|$ | 현재 프레임과 배경 모델 사이의 단순 픽셀 차이 |
| **Learning Rate ($\alpha$)** | $0.001 \sim 0.05$ | 배경 갱신 속도 (작을수록 배경이 천천히 업데이트됨) |
| **Threshold ($T$)** | $20 \sim 50$ (8-bit) | 움직임으로 간주할 최소 밝기 변화량 |
| **Background Model Type** | MOG2, KNN | 통계적 모델링을 통한 조명 변화 및 노이즈 억제 |
| **Shadow Detection** | Boolean (True/False) | 그림자를 전경 객체와 분리하여 오탐지 방지 |

## 3. 심층 분석: 동적 배경 갱신의 메커니즘 (Deep Analysis)

시간이 흘러 해가 지거나 조명이 바뀌면 고정된 배경 모델은 쓸모없게 됩니다. 이를 해결하기 위해 배경을 매 순간 조금씩 업데이트하는 **[이동 평균(Moving Average)]** 기법을 사용합니다.

1. **배경 갱신 수식**: $B_{t+1} = (1-\alpha)B_t + \alpha f_t$
2. **고스트 현상 해결**: 정차한 차량이 시간이 지나면 서서히 배경으로 편입(Ghost Removal)되도록 유도합니다. 반대로 오랫동안 멈춰있던 차가 출발하면 그 자리가 배경과 달라져 보이는 현상도 $\alpha$ 조절을 통해 극복합니다.
3. **통계적 모델링 (MOG2)**: 단순히 평균을 내는 것이 아니라, 각 픽셀의 변화를 여러 개의 가우시안 분포(GMM)로 모델링하여 흔들리는 나뭇잎이나 수면의 잔물결 같은 '반복적인 움직임'을 배경으로 간주합니다.

## 5. [코드 연결 해설 (Code Weaving)]

OpenCV의 `accumulateWeighted`와 MOG2를 활용한 배경 처리 로직입니다.

```python
import cv2
import numpy as np

# 1. 고도화된 배경 차분기 초기화 (MOG2)
backSub = cv2.createBackgroundSubtractorMOG2(history=500, varThreshold=16, detectShadows=True)

while True:
    ret, frame = cap.read()
    
    # 2. 전경 마스크 생성 (배경과 차이가 나는 부분만 1로 표시)
    fgMask = backSub.apply(frame)
    
    # 3. 그림자 제거 및 노이즈 정제
    _, fgMask = cv2.threshold(fgMask, 250, 255, cv2.THRESH_BINARY)
    
    # 4. 배경 이미지 획득 (디버깅용)
    bgImage = backSub.getBackgroundImage()
    
    cv2.imshow('FG Mask', fgMask)
    cv2.imshow('Background Model', bgImage)
    
    if cv2.waitKey(30) == ord('q'): break

# Transitional Bridge: 위 코드에서 `apply()` 함수 내부는 
# 수천 개의 가우시안 분포가 각 픽셀의 운명을 결정하는 
# 전쟁터입니다. 2026년 스마트 팩토리의 안전 펜스는 
# 이 배경 차분을 통해 '허가되지 않은 움직임'을 0.05초 만에 
# 감지하고 로봇의 긴급 정지 명령을 하달합니다.
```

## 6. [스스로 체크 (Self-Check)]

1. **질문**: 고정된 배경을 사용할 때의 문제점인 '고스트 현상'은 무엇이며, 어떻게 해결할 수 있을까요?
   - **정답**: 정지해 있던 물체가 움직이면 그 자리가 배경과 달라 보여 객체로 인식되는 현상입니다. **이동 평균 배경 갱신**을 통해 시간이 흐르면 그 자리를 다시 배경으로 편입시켜 해결합니다.
2. **질문**: `accumulateWeighted`에서 `alpha` 값이 크면 배경 모델은 어떻게 변할까요?
   - **정답**: 현재 프레임의 반영 비율이 높아져 배경이 **매우 빠르게 업데이트**됩니다. 움직이는 물체가 금방 배경으로 사라지는 부작용이 생길 수 있습니다.
3. **질문**: MOG2 알고리즘이 단순 차분보다 우수한 결정적인 이유는?
   - **정답**: 각 픽셀을 **다중 확률 분포**로 관리하여, 흔들리는 나무나 조명 깜빡임 같은 노이즈를 배경의 일부로 학습하기 때문입니다.
