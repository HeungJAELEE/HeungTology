# [[[Semiconductor] optical-flow

## 1. [왜 배우는가? (Why: Finding Motion Vectors)]]
단순히 물체가 '있다'는 것을 넘어, 물체가 '어느 방향으로, 얼마나 빠르게' 움직이는지를 아는 것은 자율 주행과 정밀 제어의 핵심입니다.
1. **속도 및 방향 예측**: 비행 드론이 지면을 바라보며 자신의 이동 속도를 계산하거나, 로봇 팔이 다가오는 물체를 가로챌 때 필요합니다.
2. **구조 분석 (Structure from Motion)**: 카메라의 이동에 따른 픽셀의 흐름 차이를 분석하여, 주변 환경의 3차원 깊이(Depth) 정보를 추론할 수 있습니다.
3. **비디오 압축**: 영상의 변화가 적은 부분은 흐름 정보만 저장함으로써 데이터 용량을 획기적으로 줄입니다.

## 2. 핵심 기술 사양 (Numerical Specs)

광학 흐름 계산의 정확도와 연산 비용을 결정하는 지표입니다.

| 항목 (Parameter) | 수식 / 사양 | 물리적 의미 |
| :--- | :--- | :--- |
| **Brightness Constancy** | $I(x, y, t) = I(x+\delta x, y+\delta y, t+\delta t)$ | 프레임 간 밝기가 변하지 않는다는 기본 가정 |
| **Flow Equation** | $f_x u + f_y v + f_t = 0$ | 픽셀 이동 속도($u, v$)와 밝기 변화율 사이의 관계식 |
| **Sparse Flow (LK)** | $O(N_{feat})$ | 특정 특징점들에 대해서만 흐름 계산 (고속) |
| **Dense Flow (FB)** | $O(W \times H)$ | 모든 픽셀에 대해 흐름 계산 (정밀, 고부하) |
| **Search Window** | $15 \times 15 \sim 31 \times 31$ | 픽셀 이동을 탐색할 주변 영역의 크기 |

## 3. 심층 분석: 밝기 항구성과 공간 근접성 (Scientific Rationale)

광학 흐름은 두 가지 강력한 가설 위에 세워진 수학적 모델입니다.

1. **밝기 항구성 (Brightness Constancy)**: "물체 위의 한 점은 움직여도 그 고유의 밝기를 유지한다." 이 가정 덕분에 우리는 미분 방정식을 통해 픽셀의 이동량을 추적할 수 있습니다. 조명이 급격히 변하는 환경에서는 이 가정이 깨지므로 보정 기법이 필수적입니다.
2. **공간 근접성 (Spatial Coherence)**: "이웃한 픽셀들은 보통 같은 물체에 속하므로 비슷한 움직임을 가진다." Lucas-Kanade 알고리즘은 이 가정을 바탕으로 주변 $3\times 3$ 영역의 흐름이 동일하다고 가정하고 연립 방정식을 풀어 흐름 벡터를 산출될 것으로 예상됩니다.
3. **Farneback Polynomial Expansion**: 정적인 픽셀 비교를 넘어, 주변 영역을 이차 다항식(Quadratic Polynomial)으로 근사화하여 모든 픽셀의 변위(Displacement)를 면밀히 계산해내는 '밀집(Dense)' 방식의 정수입니다.

## 5. [코드 연결 해설 (Code Bridge)]

OpenCV의 Farneback 알고리즘을 사용하여 영상 전체의 움직임을 색상(HSV)으로 시각화하는 코드입니다.

```python
import cv2
import numpy as np

# 1. 초기 프레임 설정
ret, frame1 = cap.read()
prvs = cv2.cvtColor(frame1, cv2.COLOR_BGR2GRAY)
hsv = np.zeros_like(frame1)
hsv[..., 1] = 255 # 채도 최대화

while True:
    ret, frame2 = cap.read()
    next_img = cv2.cvtColor(frame2, cv2.COLOR_BGR2GRAY)
    
    # 2. 밀집 광학 흐름 계산 (Farneback)
    flow = cv2.calcOpticalFlowFarneback(prvs, next_img, None, 0.5, 3, 15, 3, 5, 1.2, 0)
    
    # 3. 흐름 벡터(x, y)를 극좌표(각도, 크기)로 변환
    mag, ang = cv2.cartToPolar(flow[..., 0], flow[..., 1])
    
    # 4. 각도를 색상(Hue)으로, 크기를 밝기(Value)로 매핑
    hsv[..., 0] = ang * 180 / np.pi / 2
    hsv[..., 2] = cv2.normalize(mag, None, 0, 255, cv2.NORM_MINMAX)
    
    # 5. HSV를 BGR로 변환하여 출력
    bgr = cv2.cvtColor(hsv, cv2.COLOR_HSV2BGR)
    cv2.imshow('Optical Flow (Dense)', bgr)
    
    prvs = next_img
    if cv2.waitKey(1) == ord('q'): break

# Transitional Bridge: 위 코드에서 `flow` 벡터 데이터는 
# 로봇의 '충돌 회피' 센서 데이터로 즉시 치환될 수 있습니다. 
# 2026년 자율주행 시스템은 이 전통적 광학 흐름 데이터와 
# 'Optical Flow Net'과 같은 딥러닝 특징점을 퓨전하여, 
# 주변 사물의 상대 속도를 0.01m/s 단위로 정밀하게 측정합니다.
```

## 6. [스스로 체크 (Self-Check)]

   - **정답**: 모든 픽셀을 계산하지 않고, 이미지 내의 **유의미한 특징점(Feature Points)**들만 골라내어 그 점들의 이동만 추적하기 때문입니다.
2. **질문**: 광학 흐름 계산에서 '밝기 항구성' 가정이 깨지는 상황(예: 급격한 조명 변화)을 해결하기 위한 방법은?
   - **정답**: 픽셀 값 자체를 쓰는 대신, 이미지의 **기울기(Gradient)**나 **라플라시안(Laplacian)** 등의 특징 맵을 사용하여 조명에 강건한 특징을 추출해 계산합니다.

   - **정답**: 물체가 나에게서 멀어지는지, 다가오는지, 혹은 왼쪽/오른쪽 어느 방향으로 가로질러 가는지에 대한 **상대적 이동 방향**을 의미합니다.
